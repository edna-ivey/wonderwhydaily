A QR code works from so many angles because special position markers help the phone find the code and figure out how it is turned.

The secret starts with the three big squares in the corners, called finder patterns. They are like bright flags shouting, "The code is over here, and this is how it is turned." Once the camera finds them, software can map the tilted shape back into a neat square grid. Smaller alignment patterns help correct position and angle distortion, especially on larger codes or curved surfaces.

A QR code is not just carrying a message. It is carrying visual landmarks for how to find and read that message. That is why rotating the page does not confuse it the way rotating a line of ordinary writing might.

QR codes also use error correction, which helps recover information when part of the pattern is missing or smudged. That is a different trick from reading the code at an angle, but together they make QR codes impressively hard to fluster.

The name means Quick Response, and the format was invented in Japan to track auto parts moving through factories. It was built for a world where labels, objects, and cameras would not politely hold still. Every scan is a tiny rescue mission: find the square, flatten the view, and uncover the message hiding in the mosaic.
