A damaged QR code can still work because it is not only storing the message. It is also storing backup information about the message.

The black-and-white grid holds data, but QR codes also include error-correction data, built using a kind of math called Reed-Solomon error correction that lets missing pieces be rebuilt from the pattern around them. If part of the code is dirty, scratched, or missing, the scanner can use those backup relationships to reconstruct a limited amount of the lost information.

That does not make QR codes invincible. Cover too much of the pattern, or damage the important guide squares and timing patterns, and the scanner can fail. The code is prepared, not magical.

Designers can choose different error-correction levels. Stronger protection helps a code survive more damage, but it also uses up space that could have held more of the main message.

Every scratched QR code that still scans is doing something quietly impressive: it brought enough mathematical spare parts to repair itself in front of your camera.
